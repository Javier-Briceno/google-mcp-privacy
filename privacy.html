Privacy policy

Local Google MCP tools · last updated 8 October 2026

Who this applies to

These tools are for my private use only. The only Google accounts they access are my own. Controller: Javier Briceño.

What data is accessed

With my consent through Google OAuth, the tools access the content and metadata of my Gmail messages and drafts, and my Google Calendar calendars and events. The exact permissions are listed on the home page.

How it is used

The data is used only to answer my own requests: finding and reading mail, preparing drafts, and reading or changing calendar events. When I ask my AI assistant (Claude Code by Anthropic) to do this, the relevant content is passed to it within my own session to produce the answer. The tools never send email on their own.

Storage

OAuth tokens are stored in local files on my computer. Mail and calendar content is not copied to any server or database operated by these tools.

Sharing

The data is not sold, not used for advertising, and not shared with anyone else. It is not used to train AI models by these tools.

Google API Services User Data Policy

The use and transfer of information received from Google APIs by these tools adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token files removes the stored credentials.
