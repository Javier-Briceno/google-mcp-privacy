# google-mcp-privacy

Home page and privacy policy for my local Google MCP tools (Gmail, Google
Calendar), served with GitHub Pages. Google's OAuth consent screen needs both
URLs before the app can be published.

- Home: https://javier-briceno.github.io/google-mcp-privacy/
- Privacy policy: https://javier-briceno.github.io/google-mcp-privacy/privacy.html

When a new Google API is added to one of the tools, add its scopes to the
table in `index.html` and update `privacy.html`.
