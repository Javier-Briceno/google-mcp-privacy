Local Google MCP tools

Personal tools by Javier Briceño

A small set of MCP servers that run on my own computer and let my AI coding assistant (Claude Code) read my own Gmail and Google Calendar and prepare drafts and events for me. They are built for one user, myself. They are not a public service and nobody else can sign in to them.

What each tool does

ToolGoogle accessWhat it does
Mail gmail.readonly, gmail.compose Searches and reads my mail. Creates and deletes drafts. Never sends mail.
Calendar calendar.readonly, calendar.events Lists my calendars and events. Creates, updates and deletes events.

How it works

Each tool is a local program. It signs in with Google OAuth through a redirect to 127.0.0.1 on the same machine, keeps its token in a local file, and talks directly to the Google APIs. There is no server of mine in between and no database.
